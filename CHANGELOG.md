# AI-OS Master Changelog

## [1.0.0] - Production Release
### Added
- **Core Kernel**: Fully stable asynchronous Orchestrator routing via `KERNEL-001`.
- **Persistent Storage**: 0-data-loss `PersistenceAdapter` and lazy-loading `KnowledgePersistence` mechanisms mapped to `/domains`.
- **Ide Bridge**: Bi-directional WebSocket proxy bus actively listening on port `8080`.
- **EngineerOS**: `QualityReviewer`, `ArchitectureViewer`, and `DevOpsTracker`.
- **LearnOS**: `MasteryDashboard`, `InteractivePractice`, and integrated VS Code Status Bar telemetry.
- **CareerOS**: `ResumeDashboard` and `InterviewSimulator`.
- **StartupOS**: `LeanCanvasView` and `MVPTracker`.
- **ResearchOS**: `ComparativeView`, `EvidenceTracker`, and `ResearchDashboard`.

## [0.9.0] - Pre-Release E2E Ignition
### Changed
- Refactored all platform endpoints to operate via standard `AIOS_EXECUTE_TASK` proxy messaging.
- Migrated domain taxonomies (Python, Java, DSA, System Design) into unified structural JSON mapping protocols.

## [0.1.0] - Prototype Foundations
### Added
- Initial scaffolding for standard agent routing.
- Early prototyping of `MemoryService` (volatile runtime states).
